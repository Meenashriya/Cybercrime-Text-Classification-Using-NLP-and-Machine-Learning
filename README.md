# Cybercrime Classification and Risk Prediction using Machine Learning

## Overview
This project uses Natural Language Processing (NLP) and Machine Learning techniques to classify cybercrime incidents based on textual descriptions and analyze cybercrime patterns.

## Objectives
- Clean and preprocess cybercrime data
- Perform exploratory data analysis
- Extract text features using TF-IDF
- Build a machine learning classification model
- Predict cybercrime categories from incident descriptions

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Model
- Multinomial Naive Bayes

## Features
- Data Cleaning
- Text Preprocessing
- TF-IDF Vectorization
- Crime Type Prediction
- Model Evaluation
- New Crime Prediction
